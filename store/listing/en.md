**Description** (4000):

marktile opens Markdown files and leaves them exactly as it found them.

Double-click a .md file in Finder and it opens in a window. There is no vault to create and no library to import into. Read the same file three ways:

• Seasoned: the Markdown stays in the text, styled, so you see the structure you typed
• Rendered: the document as a reader sees it
• Plain: the raw text

YOUR FILE STAYS YOUR FILE
Open a document and save it without changes, and you get the same bytes back: trailing spaces, Windows or Unix line endings, even a mix of both in one file. marktile reads and writes UTF-8, and says so instead of guessing at another encoding.

SEARCH EVERY DOCUMENT
Press ⇧⌘F to find a word across every Markdown file in the folders you allow, including the ones Spotlight does not index, with the matching lines on screen. Chinese, Japanese and Korean need no quoting: a phrase matches as a phrase.

FOLLOWS YOUR LINKS
⌘-click a [[wikilink]] to open the note it names, beside it or anywhere in the Obsidian vault it belongs to. When several notes share a name, marktile asks which one.

MAKE IT YOURS
Choose which toolbar buttons and modes to keep, how the syntax is colored, and whether prose is set in monospace or your body font.

PRIVATE BY DESIGN
No account, no analytics, no network requests of its own. Your notes never leave your Mac.

Menus and editor in English, Japanese, Korean and Traditional Chinese.
