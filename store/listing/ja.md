**名前**（30）：marktile

**サブタイトル**（30）：Markdownを、そのままに

**プロモーションテキスト**（170）：ひとつのMarkdownを三つの読み方で。Mac中のノートから一語を探す検索は、Spotlightが拾わないファイルまで届きます。

**キーワード**（100、カンマ区切り・空白なし）：markdown,エディタ,ノート,メモ,md,執筆,テキスト,検索,リンク

**説明**（4000）：

marktile は Markdown ファイルだけを開き、開いたときのまま保存します。

Finder で .md ファイルをダブルクリックすれば、そのままウインドウで開きます。保管庫を作る必要も、読み込む必要もありません。ひとつのファイルを三つの読み方で：

・アジツケ：Markdown の記号を残したまま装飾し、書いた構造がひと目で分かる
・レンダー：読み手が見る姿
・プレーン：素のテキスト

あなたのファイルは、あなたのもの
文書を開いて何も変えずに保存すれば、バイト単位で同じファイルが戻ります。行末の空白も、Windows と Unix の改行も、ひとつのファイルに混在していても、そのまま残ります。marktile は UTF-8 だけを読み書きし、ほかのエンコーディングを推測せずにそう伝えます。

すべての書類を検索
⇧⌘F で、許可したフォルダにあるすべての Markdown ファイルから語句を探せます。Spotlight が索引しないファイルも含め、一致した行をそのまま表示します。日本語・中国語・韓国語は引用符なしで、フレーズはフレーズとして一致します。

リンクをたどる
⌘ キーを押しながら [[ウィキリンク]] をクリックすると、隣のノートでも、同じ Obsidian 保管庫のどこにあるノートでも開きます。同じ名前のノートが複数あるときは、どれを開くか尋ねます。

自分好みに
残すツールバーのボタンとモード、構文の色付け、本文を等幅にするか本文用フォントにするかを選べます。

プライバシーを設計から
アカウント不要、解析なし、アプリ自身はネットワークに接続しません。ノートが Mac の外に出ることはありません。

メニューとエディタは英語・日本語・韓国語・繁体字中国語に対応。
